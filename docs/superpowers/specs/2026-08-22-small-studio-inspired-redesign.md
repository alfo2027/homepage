# Small Studio–Inspired Portfolio Redesign

## 목표

Small Studio 레퍼런스의 대형 타이포그래피, 넓은 여백, 번호형 섹션, 흑백 색채를 활용해 현재 포트폴리오 메인을 재설계한다. 원본의 문구, 로고, 사진은 사용하지 않고 윤봉봉의 자체 콘텐츠와 교체 가능한 자리표시자를 사용한다.

## 고정 조건

- 폰트는 Pretendard를 유지한다.
- 프레임워크·빌드·JavaScript 의존성을 추가하지 않는다.
- 메인 카드는 기존 `project-01.html`~`project-03.html`에 연결한다.
- 상세 페이지는 피그마 통이미지를 넣는 단순한 구조를 유지하되 메인의 흑백 스타일과 맞춘다.

## 정보 구조

1. Hero — 대형 자기소개 문장, 보조 설명, 연락 버튼
2. Projects — 대표 이미지 중심의 2열 카드 그리드
3. About `[01]` — 왼쪽 라벨과 오른쪽 대형 소개 문장
4. Experience `[02]` — 회사·직책·기간·업무 목록
5. Contact — 둥근 검은색 패널과 이메일 버튼
6. Footer — 이름, 저작권, 상단 이동

메인 내비게이션은 `About / Experience / Projects / Contact`로 구성한다.

## 시각 체계

- 배경은 순백에 가깝게, 텍스트는 검정과 중간 회색을 사용한다.
- 히어로 제목은 `clamp()`를 사용하여 화면에 따라 크기를 조절한다.
- 섹션 사이에 넓은 수직 여백과 얇은 회색 구분선을 둔다.
- 버튼은 검은색/흰색 pill 형태를 사용한다.
- 프로젝트 자리표시자는 원본 사진을 복제하지 않고 단색과 자체 기하학 조합으로 만든다.

## Experience 변환

레퍼런스의 Services 목록 정보 위계를 이력 행으로 재해석한다. 각 행은 순번, 회사명, 직책, 기간, 주요 업무를 표시하며 실제 콘텐츠 교체 전까지 예시 이력 3개를 사용한다.

## 반응형과 접근성

- 데스크톱의 2열 히어로·프로젝트·섹션 구조는 720px 이하에서 1열로 전환한다.
- 대형 제목은 모바일에서 자동 축소하고 자연스럽게 줄바꿈한다.
- 모든 링크에 focus-visible 스타일을 제공한다.
- 동작 줄이기 설정에서 현저한 hover 전환을 제거한다.

## 검증

- 프로젝트 카드 3개와 상세 링크를 검증한다.
- `about`, `experience`, `projects`, `contact` 섹션과 내비게이션 연결을 검증한다.
- 1440px 데스크톱과 390px 모바일 화면을 시각적으로 확인한다.
- 프로젝트 상세의 통이미지·분할 이미지 지원을 유지한다.
