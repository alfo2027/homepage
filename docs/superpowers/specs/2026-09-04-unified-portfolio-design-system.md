# 통합 포트폴리오 디자인 시스템 설계

## 목표

현재 메인 홈에 확정된 시각 언어를 프로젝트 상세와 앞으로 추가될 모든 화면의 기본값으로 만든다. 새 페이지는 별도 배경·폰트·본문 컬러를 선언하지 않아도 메인과 같은 분위기를 상속해야 하며, 프로젝트 원본 이미지는 이 시스템의 색상 처리에서 제외한다.

## 공통 기반

앱 최상단에 포트폴리오 공통 클래스와 CSS 사용자 정의 속성을 둔다. 기존의 범용 토큰과 메인 전용 토큰을 중복된 값으로 유지하지 않고 다음 의미 기반 토큰을 단일 기준으로 사용한다.

- 컬러: 배경 #f7f7f5, 전경 #121212, 보조 텍스트 #777, 구분선 #d9d9d5
- 다크 컬러: 배경 #101010, 전경 #f0f0ec, 보조 텍스트 #999, 구분선 #353535
- 타이포: Pretendard, 본문·메타·카드에 사용하는 13px·15px·17px 단계
- 간격: 10px을 최소 단위로 삼고 20px·40px·80px을 주요 위계 간격으로 사용
- 모션: 200~420ms와 cubic-bezier(.22, 1, .36, 1)을 기본으로 사용

기존 클래스와의 호환이 필요한 동안에는 기존 토큰을 공통 토큰의 별칭으로 연결한다. 새 코드는 공통 토큰만 사용한다.

## 테마 상태와 흐름

라이트·다크 상태는 CaiConceptPage 내부가 아니라 앱 최상단의 테마 컨텍스트에서 관리한다. 앱 루트가 현재 테마 클래스를 소유하고 body에도 동일한 배경을 반영한다.

1. 메인 홈의 점 버튼이 전역 테마 상태를 변경한다.
2. 프로젝트 상세로 이동해도 같은 React 앱 상태가 유지된다.
3. 새 페이지는 앱 루트 아래에서 공통 컬러와 Pretendard를 자동 상속한다.
4. 직접 상세 URL을 열었을 때는 라이트 테마를 기본값으로 사용한다.

브라우저 저장소에는 기록하지 않는다. 방문마다 라이트 모드로 시작하며, 같은 방문 흐름 안에서만 사용자의 선택을 유지한다.

## 프로젝트 상세 적용

ProjectPage와 상세 내비게이션·인트로·관련 프로젝트 영역은 공통 배경·전경·보조 텍스트·구분선 토큰을 사용한다.

- 상세 전체 배경은 메인과 동일한 #f7f7f5
- 내비게이션과 주요 제목은 전경색
- 설명과 프로젝트 타입은 보조색
- 인트로와 관련 프로젝트의 타이포는 13px·15px·17px 단계 안에서 구성
- 외곽 및 내부 여백은 10px 기반의 공통 간격을 사용하되, 상세 이미지의 풀블리드 구조는 유지
- 원본 프로젝트 이미지는 필터, 투명도, 배경색 변경 없이 그대로 표시
- 다크모드에서도 이미지 자체는 변형하지 않고 주변 UI만 반전

## 새 화면 자동 적용 규칙

라우트의 최상위 요소가 앱 테마 루트 아래에 렌더링되므로 기본 배경, 글자색, 글꼴, 행간은 자동 상속한다. 새 화면은 다음 경우에만 스타일을 추가한다.

- 정보 위계를 위해 공통 타이포 단계 중 하나를 선택할 때
- 공통 간격 단위를 조합할 때
- 구분선이나 보조 면이 실제 구조 구분에 필요할 때

페이지별로 독립적인 흰색 배경, 새로운 회색, 임의 폰트 크기, 별도 그림자 체계를 만들지 않는다. DESIGN.md의 현재 규칙과 이 토큰을 함께 갱신해야 한다.

## 접근성과 반응형

- 라이트·다크 양쪽에서 텍스트 대비를 유지한다.
- 테마 버튼의 기존 접근성 이름과 키보드 조작을 유지한다.
- 모바일·태블릿 레이아웃의 열 변화는 유지하고 색상·타이포 토큰만 공통 상속한다.
- prefers-reduced-motion에서는 기존과 같이 전환을 제거한다.

## 테스트

- 메인에서 테마를 변경한 뒤 프로젝트 상세에서도 동일한 테마 클래스와 컬러가 유지되는지 통합 테스트한다.
- 상세 페이지 배경·전경·보조 텍스트가 공통 토큰의 계산값과 일치하는지 검사한다.
- 기존 홈·상세 라우팅, 프로젝트 전환, 이미지 비드래그 테스트를 유지한다.
- 전체 Vitest, 프로덕션 빌드, git diff --check를 통과시킨다.
- 데스크톱과 모바일에서 메인·상세 라이트/다크 화면을 직접 렌더링해 시각 검수한다.

## 제외 범위

- 프로젝트 원본 이미지 재편집
- 콘텐츠 문구 변경
- 상세 정보 구조 변경
- 테마 선택의 영구 저장
- 새로운 색상이나 장식 효과 추가
