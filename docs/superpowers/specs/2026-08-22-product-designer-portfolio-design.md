# Product Designer Portfolio Design

## 목표와 대상

UI/UX·프로덕트 디자이너의 취업용 포트폴리오를 실제 URL로 공개할 수 있는 정적 HTML 틀로 만든다. 주요 방문자는 채용 담당자이며, 사용자는 피그마에서 제작한 프로젝트 이미지를 추후 교체한다.

## 성공 기준

- 홈에서 지원자의 직무, 소개, 프로젝트 목록을 빠르게 파악할 수 있다.
- 프로젝트 카드 전체를 누르면 해당 상세로 이동한다.
- 상세에서 긴 이미지 하나 또는 분할 이미지 여러 장을 자연스럽게 연속해 볼 수 있다.
- 데스크톱과 모바일에서 읽기 쉬운 반응형 레이아웃을 제공한다.

## 기술 제약

- 프레임워크, 빌드, JavaScript 의존성 없이 정적 HTML과 CSS만 사용한다.
- 각 페이지는 단일 HTML 파일로 유지한다.
- 색상과 폰트 토큰은 `:root` CSS 변수로 관리한다.
- Pretendard CDN과 시스템 폰트 폴백을 사용한다.
- `DESIGN.md`를 디자인 결정의 단일 진실 원천으로 유지한다.

## 페이지 구조

### 홈

`index.html`은 Hero, About, Projects, Contact 순으로 구성한다.

- Hero: 이름, `UI/UX · Product Designer`, 짧은 소개
- About: 강점과 경력을 넣을 수 있는 간결한 텍스트 영역
- Projects: 대표 이미지, 프로젝트명, 분야, 연도로 구성된 카드 그리드
- Contact: 이메일과 연락 안내

프로젝트 그리드는 데스크톱에서 2열, 620px 이하에서 1열이다.

### 프로젝트 상세

프로젝트별 HTML은 공통 구조를 복사해 사용한다.

1. 목록으로 돌아가는 최소 내비게이션
2. 프로젝트 제목과 분야·연도
3. 포트폴리오 이미지 영역
4. 목록, 이전, 다음 프로젝트 링크

역할, 성과, 문제 정의, 과정, 결과 요약을 위한 별도 HTML 섹션은 두지 않는다. 이 내용은 피그마 이미지 안에 포함된다.

## 이미지 처리

- 단일 긴 이미지와 여러 분할 이미지를 동일한 `.project-images` 컨테이너에서 지원한다.
- 이미지는 `display: block`, `width: 100%`, `height: auto`로 원본 비율을 유지한다.
- 기본 이미지 간격을 CSS 변수로 제어하고, `.is-seamless`에서 간격을 0으로 설정한다.
- 예시 자리표시자와 HTML 주석으로 교체할 파일 경로를 명확히 안내한다.

## 시각 스타일

- Quiet Editorial의 여백과 정보 위계를 기본으로 한다.
- 웜 화이트 배경, 검정 계열 텍스트, 절제된 블루 포인트를 사용한다.
- 타이포그래피, 색상, 간격은 `DESIGN.md`의 토큰을 따른다.
- 애니메이션은 카드 hover와 smooth scroll 수준으로 제한한다.

## 접근성과 반응형

- 모든 링크는 키보드로 접근 가능하고 명확한 focus 스타일을 갖는다.
- 텍스트와 배경은 WCAG AA 수준의 대비를 유지한다.
- 이미지는 내용을 설명하는 `alt`를 갖는다.
- 620px 이하에서 그리드와 하단 내비게이션을 한 열로 재배치한다.

## 검증

- 모든 로컬 링크와 이미지 경로를 확인한다.
- 홈 카드에서 상세로 이동하고 목록으로 돌아오는 흐름을 확인한다.
- 긴 이미지 1장과 분할 이미지 여러 장의 표시를 각각 확인한다.
- 데스크톱과 620px 이하 모바일 화면을 시각적으로 확인한다.
